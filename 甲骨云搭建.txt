二十、这次修改的硬性原则

我建议把下面这段直接作为这次修改脚本的设计约束：

1. 不重写系统监控核心逻辑
2. 不删除现有系统监控项目
3. 仅增加 oci-free-guard.timer
4. 不重复增加 ollama
5. 不重复增加 oci-linux-lab
6. 不创建第二个 oci-free-guard.timer
7. 不把 OCI 判断写死
8. 不让 Ollama 决定计费状态
9. 不把 Linux 网卡 TX 当成 OCI 月度流量
10. 不把 200GB OCI 配额使用率和 Linux 磁盘使用率混淆
11. 防火墙从总览移动到安全
12. 防火墙必须实际读取 UFW
13. 防火墙支持增加、修改、删除、启用、禁用
14. 所有防火墙修改必须确认
15. 所有输入严格验证，禁止 shell injection
16. BBR 从总览/安全移动到 sing-box → 网络优化
17. 保持 Python / JS / Guard 模块化
18. 修改后必须重新检查实际服务、UFW、sing-box、Panel API

这就是后面实际写代码的基准版本。
